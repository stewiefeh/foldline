# Foldline

A concept site for a fictional two-person knife forge in Duluth, Minnesota. Built from scratch: no frameworks, no build step, no external dependencies.

- `index.html` — single page
- `css/style.css` — all styling, local variable fonts only (Fraunces, Hanken Grotesk)
- `js/main.js` — nav state, reveals, the layer count, the steel swatch that swaps the macro photograph and spec, demo reservation form
- `assets/` — all imagery generated for this concept (credited in the footer)

Live: https://stewiefeh.github.io/foldline/

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
